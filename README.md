# 🏢 AIM-Office

**Sovereign Isometric 2.5D Pixel-Art Agent Command Center for the A.I.M. / J.O.S.H.U.A. Ecosystem**

AIM-Office transforms your live multi-agent `tmux` fleet into an interactive, isometric 2.5D pixel-art command center. Watch autonomous agents (`AGY`, `Grok`, `OpenCode`, `Codex`) work at their desks, walk `aim-communicate` dispatches across the office, update the GitHub Projects Kanban whiteboard, and surface live 30%-Rule Context Window telemetry.

## ✨ Core Features

- **Live Multi-Vessel Fleet Simulation:** Connects directly to `aim-connect` (`GET /api/fleet/panes`) to map every active `tmux` session to an isometric workstation with vessel-specific pixel-art avatars.
- **30%-Rule Context & Amnesia Alerts:** Real-time context meters above each agent; agents crossing the `30%` threshold display visual heat/sweat alerts and trigger handoff workflows (`/aim-memory-wiki` & `/aim-handoff`).
- **Physical `aim-communicate` Courier Walks:** Polls `GET /api/swarm/activity` to animate agents walking dispatches from their cubicle to `aim-joshua`'s Boss Desk or peer workstations.
- **Interactive Kanban Whiteboard & Memory Vault:** Click the office whiteboard to inspect `aim projects board` or the server vault to inspect `memory-wiki/` and active `workspace/issue-*` git worktrees.
- **100% Original Sovereign Artwork:** All isometric rooms, furniture layers, and 4-direction character sprites (`front-left`, `front-right`, `rear-left`, `rear-right`) are originally generated and sliced via the built-in Python `Pillow` sprite pipeline.
